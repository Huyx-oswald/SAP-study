业务场景：接单决策成本测算

市场拿到一个新订单，总经理需要决策是否接单。成本会计的任务是根据大致的BOM和工艺路线，快速测算订单成本，为定价与接单决策提供依据。本节梳理成本构成与四类取数来源。

业务背景 该场景属于"按订单设计/按订单生产"的报价成本估算，与正式标准成本估算（CK11N发布到物料标准价）的区别在于：报价估算通常不发布价格，仅用于决策测算；若使用销售订单BOM，可用 CK51N 做销售订单成本估算并保留结果。

核心事务码与表

MM03

物料主数据显示

会计视图1：标准价（STPRS）、移动平均价（VERPR）、价格控制（VPRSV：S标准/V移动平均）、价格变更日期。报价测算主要看此处。

ME13

采购信息记录显示

供应商-物料-工厂组合的净价、有效期、起订量、条件记录。最新供应商报价应优先取自此处。

CKM3

物料价格分析

启用物料分类账后，可查物料多级价格差异、实际单位成本构成，分析材料价格变动对成本的影响。

MBEW

物料估值表

物料估值数据存储表，含 STPRS标准价、VERPR移动平均价、ZPLPR未来计划价、VPRSV价格控制、LAETR最后价格变更日期，便于批量取数。

MR21

价格变更

手工调整物料价格（标准价或移动平均价）。报价取数时应注意物料是否近期被MR21调价。

S_ALR_87013199

物料价格分析报表

按期间筛选标准价格变动物料清单，批量核查近期材料价格调整情况，确保报价取数基于最新价。

取数建议 报价测算时先用 ME1P（采购信息记录价格清单）导出关键料最新信息记录净价；对无信息记录的料用 MM03 取移动平均价；启用物料账的料可用 CKM3 查实际成本构成作参考。务必检查"最后价格变更日期"是否近期。

工序作业价格取数

这是本场景的核心问题：工时费用和能耗费用的单价从哪里取。在SAP中，工序作业成本通过活动类型（Activity Type） × 成本中心 维护单价，工艺路线中作业消耗量乘以该单价即得工序成本。作业单价分计划价与实际价两套体系。

计划作业价格取数（报价主用）

报价成本核算主要使用计划作业价，因为它在期初已确定、稳定可预期，适合决策测算。三步走：KP06计划费用 → KP26计划作业量 → KSPI算计划单价。

KP06

成本要素/作业投入计划

按成本中心×成本要素（或作业类型）维护计划费用：人工资、折旧、电费、维修费等。这是作业单价的分子来源。

KP26

作业输出/价格计划

按成本中心×作业类型维护计划作业输出量（如计划总工时、机时）和计划单价（固定价+变动价）。这是作业单价的分母来源。

KSPI

迭代计划价计算

系统自动算：计划作业单价 = 计划总费用（KP06）÷ 计划作业量（KP26）。考虑成本中心间相互提供服务，迭代计算直至收敛。

KL01

作业类型主数据

定义作业类型（如人工工时LABOR、机器工时MACHINE、电kWh、水kg），含作业单位、分摊成本要素、实际价指示符。KL01/KL02/KL03维护。

实际作业价格取数（月结复核用）

实际价用于月末复核与订单重估：FI实际费用归集 → KSS2费用分割 → KSII算实际单价 → CON2重估订单。报价阶段一般不取实际价（因为本期还没结束、实际价未出），但历史实际价可作下期报价参考。

KSS2

成本中心实际费用分割

把成本中心归集的实际费用按分割结构（OKES定义、OKEW分配）分到各作业类型，使每类作业承担相应费用。是KSII的前置步骤。

KSII

实际作业价计算

实际作业单价 = 实际总费用（KSS2分割后）÷ 实际作业总量（KB21N计上）。迭代计算跨成本中心相互服务，更新次级成本要素43类金额。

KSBT

成本中心报表

值类型1=计划价（KP26），值类型4=实际价（KSII）。一键对比计划vs实际作业单价，核查差异来源，是月结复核的核心报表。

CON2

实际价重估订单

用KSII算出的实际价重新评估订单已用作业量，把计划价与实际价的差额补计到生产订单，使订单成本由计划价转为实际价口径。

KB21N

作业实际数量计上

把成本中心实际提供的作业量（如实际工时/机时/电耗）计上到接收方订单/成本中心，是KSII算实际价的分母来源。

S_ALR_87013611

成本中心计划/实际/差异报表

成本中心层面看计划费用vs实际费用、计划作业量vs实际作业量、差异，定位作业单价偏差根因（费用超支还是产量不足）。

报价取数要点 报价阶段取计划作业价（KP26平均价列或KSPI迭代后值）。若历史数据可信，也可参考上期 KSII 算出的实际作业价。切勿直接用 KP06 单列费用除以任意产量——必须用 KSPI 统一迭代后的单价，否则会漏算成本中心间相互服务的成本分摊。

能耗费用取数

能耗（电、水、蒸汽、压缩空气、燃气等）是制造费用的重要组成，也是工序作业成本的关键来源。SAP中有两种主流处理方式，报价取数均通过作业单价体现。

方

方式一：作为活动类型

把电定义为作业类型 ELEC（单位kWh）、水为 WATER（单位t），由能源成本中心（如动力车间）作为发送方提供。流程与人工/机时一致：

KP06 计划动力车间总费用 → KP26 计划供电量(kWh)/单价 → KSPI 算电单价（元/kWh）。

工艺路线中作业步骤关联 ELEC 作业类型及消耗量，CK11N 自动取电单价×消耗量计入能耗成本。这是最规范、最推荐的方式。

B

方式二：作为成本要素归集

电费作为初级成本要素（如 600000 电费）归集到动力成本中心，再通过分割结构（OKES）按比例分摊到主作业类型（人工/机时）。这种方式能耗"打包"在加工费里，无法在成本估算明细中单独列示电费。

若要在报价单中单独显示能耗，必须采用方式一定义为活动类型。

报价成本估算执行

四类取数就绪后，通过成本估算事务码把BOM、工艺路线、作业价格、材料价格、加成率组装成完整报价成本。核心事务码：CK11N（物料成本估算，带数量结构）、CK51N（销售订单成本估算，按订单BOM）、CK40N（批量）。

成本核算变式与评估变式

估算前先在 SPRO 配置好成本核算变式（OKKN），它包含四个关键组件：

变

成本核算类型

决定结果更新到哪个价格字段（标准价/商业价/税务估价）。报价通常选不更新价格的类型，仅作测算。

评

评估变式

定义材料价、作业价、加成的取价策略序列（见第二节）。报价建议优先信息记录净价→移动平均价→标准价。

日

日期控制

定义估算有效期区间，决定取哪个时点的价格。报价建议设为"当前日期"，取最新价。

量

数量结构控制

决定用哪个BOM/Routing展开。报价用销售订单BOM（专用）或工程BOM（粗略）。仅展开"成本核算下达"状态的BOM。

成本分析开展方法

成本分析的目的是找出成本偏差的根因、归集责任、支持改善决策。SAP提供从物料、订单、成本中心、获利能力四个层面的完整分析工具链。开展成本分析建议遵循"五步法"。

确定分析对象与口径

明确分析对象（某产品/某订单/某成本中心/某客户群），并对齐口径：是标准成本口径还是实际成本口径？是否启用物料分类账实际成本？期间范围？只有口径一致，对比才有意义。

差异分解（核心）

SAP生产订单差异分析把标准vs实际的差异自动分解为9类，定位责任：

入

投入侧差异（5类）

  • 投入价格差异：作业单价或采购价偏离标准（KSII实际价≠计划价）
  • 投入数量差异：BOM/Routing用量偏离标准（如多用材料、多耗工时）
  • 资源使用差异：使用了BOM/Routing外的替代料或作业
  • 剩余投入差异：无法归入以上的投入差异
  • 废品差异：产出报废导致的成本损失
出

产出侧差异（4类）

  • 混合价差异：同一物料多版本标准价混用
  • 产出价格差异：产出评估价偏离标准
  • 批量差异：实际产量偏离计划，固定费分摊不均
  • 剩余差异：无法归入以上的产出差异

根因定位

结合9类差异，按"差异类型 → 责任部门 → 主数据/执行根因"三层追溯。例如投入价格差异大→查 KSII 实际作业价 vs KP26 计划价→若是人工价偏高→查 KP06 计划工资 vs FI 实际工资→定责HR/车间。

改善与反馈

把分析结论反馈到三处：①修订主数据（BOM/Routing/作业价 KP26）；②优化业务执行（降低损耗、提高OEE）；③调整预算与标准（下期 CK40N 重估标准价）。形成"标准→执行→差异→改善→新标准"的闭环。

闭环要点 PDCA 的关键在「Act 反哺」——把差异分析结论真正落到 KP26 作业价、BOM 用量、Routing 工时三项主数据的修订上，否则差异分析只停留在报告、不产生改善。建议每月结账后召开成本评审会，由成本会计、车间、采购共同认责9类差异并形成修订动作清单。

💡 实战总结

本案例完整模拟了一个月的成本核算全流程，核心数据流转如下：

  • 投入端：原材料7,400元 + 人工1,250元（实际价）+ 机器1,050元（实际价） = 总投入9,700元（含辅助费用分摊）
  • 产出端：齿轮组件20个入库4,000元 + 齿轮箱8台入库4,000元 = 总产出8,000元（按标准价）
  • 差异端：订单#1001差异433元（作业价格差异）+ 订单#1002 WIP 1,267元 = 差异+WIP合计1,700元
  • 物料分类账：差异433元分摊到销售成本270.6元 + 期末库存162.4元 = 433元 ✅ 平衡

通过本案例可以清晰看到：SAP CO的成本核算是一个"标准价归集→实际价调整→差异分摊"的闭环过程。理解了这个闭环，就掌握了制造业成本会计的核心逻辑。
